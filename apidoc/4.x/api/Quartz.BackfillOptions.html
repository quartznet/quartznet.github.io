The most slots the range may hold. A range holding more is refused whole with ArgumentException, whose message says how many it holds. Defaults to DefaultMaxSlots; below 1 is refused.

Spacing

How far apart the firings start: the range's slot i, counted from 0, starts at now plus i × Spacing. Defaults to zero, which starts every slot now. A negative spacing is refused.
