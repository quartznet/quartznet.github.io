Remarks

A trigger carrying a continuation is stored in Awaiting and is never acquired while it is there. The parent's completion settles it, inside the parent's own lock and transaction: a matching outcome releases the trigger into the ordinary schedule, and any other outcome deletes it. Whichever node completes the parent is the node that settles, so a continuation survives the failure of the node that scheduled it. A one-shot parent lost with the node running it is deleted by cluster recovery, so its continuations are settled as for a deleted parent, and the recovery firing — under a key of its own — settles nothing.

The parent is a TriggerKey rather than a JobKey because a continuation waits for one firing, and a job may be fired by several triggers. The one-call scheduling overloads answer with the key to use as TriggerKey.

StartTimeUtc stays a floor rather than a schedule: releasing a continuation sets its next fire time to the later of "now" and its start time, so "an hour after the import, and never before nine" is expressible. A calendar the trigger names moves that instant on to the next one it includes, and a continuation whose EndTimeUtc is behind it by then is discarded rather than released.

Wait for the given trigger's firing, and be released when it ends in one of the named ways.

public static Continuation After(TriggerKey parent, ContinuationCondition condition = ContinuationCondition.OnSuccess)

Parameters

parent TriggerKey

The trigger whose firing to wait for.

condition ContinuationCondition

The outcomes that release the wait. Any other outcome discards the continuation, so OnSuccess — the default — means "run this only if that one worked".

Returns

Continuation

Remarks

The parent has to be in the store when the trigger carrying this is stored, or the store refuses it with ObjectDoesNotExistException naming both keys. A one-shot parent is deleted once it has fired, so schedule the continuation before the parent can finish, or check the parent's key.

Exceptions

ArgumentNullException

parent is null.

ArgumentOutOfRangeException

condition names no outcome at all, or names a value that is not an outcome. A condition nothing satisfies would discard the continuation whatever the parent did, which is a schedule nobody means to write.
