FailedFinally

Narrows the page to the executions that failed for the last time, or to everything else.

public bool? FailedFinally { get; init; }

Property Value

bool?

Remarks

true lists the rows where the job failed and the trigger did not answer with another attempt — the occurrences that gave up. false lists every other row, and null, the default, lists them all. It is a question Succeeded alone cannot ask: a job under a retry policy writes a failed row per attempt, so filtering on failure shows one occurrence several times over.
