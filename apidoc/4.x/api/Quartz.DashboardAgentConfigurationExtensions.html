Remarks

Use, because the agent is middleware over the scheduler's lifecycle: it starts with the scheduler, reconnects for as long as the scheduler runs, and says goodbye when it shuts down. The dashboard it dials has to accept agents: AddQuartzDashboard(o => o.AcceptAgents(…)).

A scheduler with an agent records its execution history, as a scheduler serving the HTTP API does, because the dashboard's History page reads it through the agent: in memory and bounded by default, in the database with UseExecutionHistory() on a persistent store. It also publishes its live events, which the Live Logs page reads the same way.
