Input

The input the run was given — the string the scheduler stored under JobInput — or null when none was recorded.

public string? Input { get; init; }

Property Value

string

Remarks

Recorded only with RecordInput, because a job's input can hold secrets, and only up to MaxInputBytes. Passing it back under JobInput to TriggerJob(JobKey, JobDataMap?, CancellationToken) runs the job with what it had, which is what the dashboard's Run again does.

A listing is entitled to leave it out, as it leaves out Log, and GetExecution(string, string, CancellationToken) always carries it.

Remarks

Remarks

This is what tells a row that says "failed, and will be tried again" from one that says "failed, and that was the last word". A row with Succeeded false and this false is a final failure — which is what FailedFinally selects and what the dashboard offers to run again.
