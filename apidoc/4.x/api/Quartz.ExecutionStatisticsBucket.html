Remarks

A run is counted by its EffectiveResult, so a row written before 4.4 counts as succeeded or failed.

The durations are over every run in the bucket, whatever its result. A percentile interpolates between the two runs nearest its rank, as SQL's PERCENTILE_CONT does: with the durations sorted, the p-th percentile of n runs lies at position (n - 1) * p.
