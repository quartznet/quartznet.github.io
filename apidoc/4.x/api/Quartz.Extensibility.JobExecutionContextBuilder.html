Builds the execution context a job's Execute(IJobExecutionContext, CancellationToken) is handed, so that a job can be called directly — in a unit test, most usually — without a scheduler firing it.

Remarks

JobExecutionContextBuilder.For(job).WithJob(detail).WithTrigger(trigger).FiredAt(when).Build() builds the context Quartz itself builds, a JobExecutionContextImpl, and every part of that chain but For<TJob>(TJob) and Build() can be left out.

What is left out is what a firing would have: a job detail of the job's own type, a trigger that fires once for it, fired now and on time, not recovering, never retried or refired, with no calendar and a token nothing cancels but an interrupt. The previous fire time is the trigger's own and the next is the one its schedule gives after this firing, skipping what the calendar excludes, as a job store reports them. There is no scheduler unless WithScheduler(IScheduler) gives one, so a job that uses Scheduler needs one — a fake is enough.

"Now" and JobRunTime are read from System unless WithTimeProvider(TimeProvider) gives another clock. The scheduler is not asked for its clock: a faked scheduler answers with a faked one. The run begins when the context is built.

The trigger is copied before it is used, as a job store copies the trigger it fires, so the trigger passed to WithTrigger(ITrigger) is not changed by the fire-instance id, the input, the retry attempt or the recovery data the context is given, and one builder can build any number of independent contexts.

Remarks

A recovering context's trigger carries what a job store's recovery trigger carries: the FailedJobOriginalTriggerName and FailedJobOriginalTriggerGroup of the trigger it stands for, which RecoveringTriggerKey reads, and that firing's fire times as FailedJobOriginalTriggerFireTime and FailedJobOriginalTriggerScheduledFireTime. The trigger stands for itself, fired at the times this context reports. A trigger whose job data already names an original trigger keeps all four as it has them.

public JobExecutionContextBuilder WithRetryAttempt(int retryAttempt)

Parameters

retryAttempt int

0 on a regular fire, n on the n-th retry.

Returns

JobExecutionContextBuilder

Remarks

It is written to the copy of the trigger, where a job store writes it and where the context reads it. The last attempt is the one whose count equals the policy's MaxAttempts; give the trigger or the job type a policy for RetryPolicy to answer one. Left out, the trigger's own count stands, which is 0 for a trigger that has never been retried.

Exceptions

ArgumentOutOfRangeException

retryAttempt is negative.
