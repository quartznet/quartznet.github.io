Remarks

What TriggerJobAndWait(IScheduler, JobKey, TimeSpan, CancellationToken) and WaitForFiring(IScheduler, TriggerKey, TimeSpan, CancellationToken) answer with, the same in process and on a cluster: Execution is the row the execution history recorded for the run, or the row it would record.

Never the job and never the exception: the history keeps neither, so a cluster could not answer with them. The job's own message is ExceptionMessage.
