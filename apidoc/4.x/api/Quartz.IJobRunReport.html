What a job says its run achieved, set as Result.

public interface IJobRunReport

Remarks

The execution history reads it when the job has returned. A cancelled run is recorded as Cancelled, and a run that threw as Failed, whatever the report says; Summary and Metrics are recorded in every case.

To have the scheduler act on a failure — retry it, run OnFailure continuations — throw. A reported Failed is history only.

JobRunReport is the shipped implementation.

Properties

Metrics

Named values the run measured, or null. Recorded as one JSON object of at most MaxMetricsLength characters; a larger one, or one with a value that throws while it is written, is dropped whole and the run is recorded without it.
