MaxMetricsLength

The longest the Metrics may be as JSON: 4,000 characters. A larger object is dropped whole, and log event 1059 says so.

Remarks

The JSON escapes every character outside ASCII, so the limit is also 4,000 bytes.

MaxSummaryLength

The longest Summary the history keeps: 1,000 characters. A longer one is cut, never between the two halves of a surrogate pair.

public const int MaxSummaryLength = 1000

Field Value

Properties

Metrics

Named values the run measured, or null. Recorded as one JSON object of at most MaxMetricsLength characters; a larger one, or one with a value that throws while it is written, is dropped whole and the run is recorded without it.

public IReadOnlyDictionary<string, object?>? Metrics { get; init; }

Property Value

IReadOnlyDictionary<string, object>

Remarks

A value is written as a JSON string, number, boolean or null: numbers stay numbers (a non-finite double or float is a string), dates are round-trip ("O") strings, a TimeSpan is its constant ("c") form, an enum is its name, and anything else is its invariant-culture text. A value whose text throws drops the metrics, with log event 1060; the run is still recorded.
