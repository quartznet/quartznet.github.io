Remarks

When the pause was made is not here: the store stamps it from the scheduler's own clock, and answers all three on PauseInfo.

Details that say nothing — neither text set, or both blank — are the reasonless pause, as null is: nothing is recorded, and the pause is made exactly as the reasonless member makes it.

A context object rather than two parameters, so the next thing a pause carries is a property rather than an overload.
