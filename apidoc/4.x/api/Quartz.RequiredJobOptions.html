Remarks

The job is named by Name and Group rather than by a JobKey, so a configuration section binds onto it: { "Name": "nightly-report", "Group": "reports", "SucceededWithin": "1.02:00:00" }. In code, RequireSuccessWithin(JobKey, TimeSpan, HealthStatus) adds one.

The requirement is met while the job's LastSucceededAtUtc is within SucceededWithin of now, on the scheduler's clock. A skipped run counts as a success. A job with no recorded success is judged from the first time the check evaluated it.
