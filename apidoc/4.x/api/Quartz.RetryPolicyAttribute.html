Remarks

Declared on the job rather than stored with it, for the reason JobTimeoutAttribute is: whether a job is safe to retry is a property of its code, and an attribute travels with the type through every job store, wire format and way of scheduling. Nothing is written to a trigger's row: the policy is looked up each time a firing fails, so it covers triggers stored before it was declared. It is inherited from a base class or from an interface the job implements, and the type's own declaration wins over an interface's.

The constructors are the factories of RetryPolicy, with each TimeSpan spelled as a string in its invariant form, because a TimeSpan cannot be an attribute argument:

AttributePolicy
[RetryPolicy(3, "00:05:00")]Fixed(int, TimeSpan)
[RetryPolicy(5, "00:00:30", 2, MaxDelay = "00:10:00", Jitter = 0.2)]Exponential(int, TimeSpan, double, TimeSpan?, double)
[RetryPolicy("00:00:10", "00:01:00", "01:00:00")]Explicit(params IReadOnlyList<TimeSpan>)
[RetryPolicy(0)]None: never retried, whatever the scheduler's default

An argument that is not a policy is refused. The attribute throws as it is read, and the scheduler reads it when the job is added or scheduled, so AddJob and ScheduleJob fail with a SchedulerException naming the job type.

public RetryPolicyAttribute(int maxAttempts, string delay)

Parameters

maxAttempts int

How many times to retry after the first failure; at least one.

delay string

The wait before each retry, as an invariant TimeSpan: "00:05:00" is five minutes.

Exceptions

ArgumentException

delay is not a TimeSpan.

ArgumentOutOfRangeException

maxAttempts is less than one, or delay is negative.

RetryPolicyAttribute(int, string, double)

Declares Exponential(int, TimeSpan, double, TimeSpan?, double): a wait that grows by factor with every retry. MaxDelay and Jitter are its other two arguments.

public RetryPolicyAttribute(int maxAttempts, string initialDelay, double factor)

Parameters

maxAttempts int

How many times to retry after the first failure; at least one.

initialDelay string

The wait before the first retry, as an invariant TimeSpan.

factor double

What each wait is multiplied by to get the next one; at least 1.

Exceptions

ArgumentException

initialDelay is not a TimeSpan.

ArgumentOutOfRangeException
