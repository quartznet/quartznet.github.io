Remarks

Spelled target/name — prod/reporting for a window onto the store attached as prod, w1/QuartzScheduler for the scheduler the HTTP target w1 fronts — and as the bare name for a scheduler that is reached through no target: one of this process, or one AddQuartzHttpClient registered without a Target. A bare key never resolves to a targeted scheduler, so a deployment that fronts one process per name sees nothing change, and two targets may front schedulers of one name without either of them taking the bare key.

Public because a replacement IQuartzApiClient receives keys and needs the one rule for reading them. SchedulerName is positional and Target defaults to null, so new SchedulerRef("x") is the bare form.
