Examples

[QuartzJob]
[SimpleTrigger("00:10:00")]
[SimpleTrigger("00:00:05", Name = "warm-up", RepeatCount = 3)]
public sealed class PollInboxJob : IJob
{
    public ValueTask Execute(IJobExecutionContext context, CancellationToken cancellationToken = default)
    {
        return default;
    }
}

Remarks

The trigger starts when the scheduler is built, as any AddTrigger<T> without StartAt does: it fires as the scheduler starts, then once per interval.

The interval is read at build time. One that is not a positive TimeSpan, and a RepeatCount below -1, are QZ0005 rather than an exception while the host starts, and the generated registration carries the interval as ticks, so nothing parses it at run time.

This attribute says nothing on a class that does not also carry QuartzJobAttribute, and the generator reports QZ1003 rather than letting a schedule be declared and silently ignored.

Constructors

SimpleTriggerAttribute(string)

Declares the interval as a TimeSpan in its invariant form — "00:10:00" is ten minutes, "1.00:00:00" is a day.

Parameters

interval string

The time between firings, as a positive invariant TimeSpan.

Remarks

A string, because TimeSpan is not something an attribute argument can be. The format is Parse(string, IFormatProvider)'s, parsed with the invariant culture, as JobTimeoutAttribute's is.

Exceptions

ArgumentNullException

interval is null.

ArgumentException

interval is not a TimeSpan.

ArgumentOutOfRangeException

interval is zero or negative.

Properties

ConfigurationKey

A configuration key whose value, when it is set, is the interval the trigger fires on instead of Interval. Defaults to none: the schedule is the attribute's.

public string? ConfigurationKey { get; init; }

Property Value

string

Remarks

Read from the container's IConfiguration as the scheduler is built, so "Jobs:Poll:Interval" is the Interval value of the Jobs:Poll section, or the environment variable Jobs__Poll__Interval. The constructor's interval stays required: it is checked at build time, and it is the schedule wherever the key is not set or no IConfiguration is registered. Only the interval is read; RepeatCount and the rest stay the attribute's.

A configured value is not checked at build time. One that is not a positive invariant TimeSpan, an empty one included, stops the host from starting with a FormatException naming the key, rather than leaving a schedule that never fires.
