How one trigger's runs have gone: its last run, its last success and failure, and its counts. The members of JobRunStatus, for the firings of one trigger rather than of one job.

Remarks

Kept by the history store beside the rows, from the executions it records, so it survives the rows being trimmed. It is folded by the rule a job's status is folded by. The counts start when the store first recorded the trigger.

It counts the firings of this trigger's key, other than one after which the trigger is finalized: a one-off trigger's only firing, and the last firing of a series, leave no status. A manual run, a backfill and a recovered firing run under triggers of their own, so they are not counted here, and a successful one does not clear ConsecutiveFailures as it clears the job's. A store of your own decides which firings it folds.

The Last* run fields describe the execution that fired latest. A run that completes after a later-fired one is counted but does not replace them.
